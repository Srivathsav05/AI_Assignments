# Assignment 1 - Diabetes Prediction using Machine Learning

## Objective
Build a Machine Learning classification model to predict whether a patient is likely to have diabetes based on medical attributes.

## Dataset
- File: `diabetes.csv`
- Total Records: 768
- Total Columns: 9
- Target Variable: `Outcome`
  - 0 - No Diabetes
  - 1 - Diabetes

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Tasks Completed
1. Data Loading and Exploration
2. Data Preprocessing
3. Handling Missing Values
4. Train-Test Split
5. Logistic Regression Model Building
6. Model Training and Prediction
7. Model Evaluation
8. Performance Analysis

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC-AUC Score

## Files
- `Diabetes_Prediction.ipynb` - Complete Python implementation.
- `diabetes.csv` - Dataset used for training and testing.
